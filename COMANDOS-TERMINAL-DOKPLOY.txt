----------------------

---------------------------

  SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

Error: "Duplicate entry"
→ Los usuarios ya existen. Elimínalos primero:
  DELETE FROM users WHERE username IN ('maria.garcia', 'carlos.mendoza', 'ana.rodriguez');

Error: "Access denied"
→ Verifica que estés usando el usuario y contraseña correctos de Dokploy

Error: "Unknown database"
→ Verifica que la base de datos se llame 'cacao_monitoring'
  Puedes ver las bases de datos con: SHOW DATABASES;
